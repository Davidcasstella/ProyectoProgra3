# ProyectoProgra3

ProyectoProgra3 es una aplicación tipo **Rappi**, enfocada en ofrecer servicios de entrega rápida utilizando bicicletas.  
El sistema permite gestionar pedidos, repartidores y clientes de forma eficiente, priorizando la sostenibilidad y la movilidad urbana.

## 🧠 Tecnologías utilizadas
- **Backend:** Spring Boot  
- **Frontend:** Angular  

Este proyecto combina un backend robusto con una interfaz moderna y responsiva, garantizando un flujo ágil entre los usuarios y los repartidores.

### Backend (Spring Boot)
1. Abre el proyecto backend en tu IDE (por ejemplo, IntelliJ o Eclipse).  
2. Asegúrate de tener configurado **Java 17+** y **Maven**.  
3. En la terminal, ejecuta el siguiente comando:

   ```bash
